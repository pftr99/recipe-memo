# 料理メモアプリ

料理名と「どこに保存したレシピか」を記録して検索できる、スマートフォン向けの小さなブラウザアプリです。

## 使い方

`index.html` をスマートフォンまたはパソコンのブラウザで開いてください。

- 「＋ 料理を登録」から料理名・保存場所・リンク・備考・タグを登録します。
- 「登録した料理」から、保存済みの料理をすべて一覧で確認できます。
- 「タグ管理」から好きなタグを作成・削除できます。
- トップ画面の検索欄で、料理名・保存場所・備考・タグをまとめて部分一致検索できます。

## データについて

登録した料理とタグは、そのブラウザの `localStorage` に自動保存されます。サーバーへの送信、ログイン、データベースは使用しません。

そのため、同じ端末・同じブラウザで開けばデータは残ります。一方で、ブラウザのサイトデータを削除した場合や別の端末・別のブラウザに移った場合は、データは引き継がれません。

## ホーム画面への追加

AndroidのChromeでホーム画面に追加すると、`icon.png` がアプリアイコンとして使われます。
